# CocoHonor concept website

This repository powers the public, concept-stage CocoHonor website. It is a static site made with HTML, CSS, and JavaScript; it has no build step or commerce system.

## Pages

- index.html — introduction and guided story path
- story.html — brand idea and principles
- material.html — sourcing questions and material-development journey
- medal.html — illustrative medal concept
- partners.html — potential collaborators and contact placeholder

The render in assets/medal-concept.png is AI-generated concept art of an imagined, unmanufactured object. Sourcing, partnerships, and impact are framed as work in progress, not verified claims.

## Edit and publish

GitHub Pages is configured to publish the main branch from the repository root. To update the site, edit the files, commit the changes to main, and push them to GitHub. Pages will rebuild automatically. Keep index.html at the repository root and preserve the relative links between pages and assets/.

The public preview is https://xritux.github.io/cocohonor---site/. The custom domain CocoHonor.com is not connected yet. To connect it, add the domain in Settings > Pages, then set the DNS records GitHub specifies at the domain registrar and enable HTTPS after verification.

## Before launch beyond the concept stage

- Replace hello@cocohonor.com in partners.html if that address is not active.
- Replace concept art with approved prototype photography when available.
- Add verified sourcing, maker, product, shipping, privacy, and contact details before accepting orders or making quantified sustainability claims.
